# aurora

Thème omaLauncher / Omarchy — choix libre — aurores depuis l'orbite

Aurores et airglow vus depuis l'ISS : bande verte et magenta le long du limbe, structures de la station en silhouette. Noir, vert froid, magenta.

## Install

Settings → Theme → coller l'URL du dépôt :

    github.com/marc26712/omarchy-aurora

## Contenu

- `colors.toml` — palette (dark)
- `backgrounds/` — 3 fonds 1080×2400 (9:20)

## Crédits images

NASA / ISS (domaine public). Recadrages et étalonnage internes.
